## 五、打卡

### 5.1 两种打卡方式

| 方式 | 谁用 | 怎么做 |
|---|---|---|
| **考勤机刷脸**（推荐） | 在厂区 / 车间上班的人 | 上下班直接到考勤机刷脸 |
| **手机远程打卡** | 驻外、出差、临时在别的点干活 | 菜单「远程打卡」，需**同时满足**：① 管理员已给你开通；② 你已录过人脸 |

### 5.2 远程打卡操作步骤

1. 左侧菜单点「**远程打卡**」。
2. 浏览器问定位权限 → 点"允许"。**厂房里信号弱，最多等 20 秒**。
3. 系统核对位置：位置在打卡范围内才会打开摄像头。
4. 再问摄像头权限 → 点"允许"，把脸对准画面。页面显示"本次打卡将记为：上班 / 下班 / 午间"。
5. 点「**打卡**」，等结果：显示记成什么类型、打卡时间、位置、考勤状态。

**系统怎么判断这次是上班还是下班**：还没打过卡算上班；快到下班时间算下班；中间时段再打卡只留识别记录，不影响上下班状态。

### 5.3 打卡规则速记

- 两次打卡要隔 **30 秒**（防手快连点）；"上班卡紧接着打下班卡"不受限制。
- 每天打卡次数**不限**。
- 班组配了**打卡地点范围**的，必须在范围内才能打（手机定位有误差，系统留了容差）。
- 人脸识别连续失败几次，要等一会儿再试。
- **午间必打卡**：你的班次如果设了午间窗口（如 12:00–13:00），要在窗口内打一次。窗口结束后 **30 分钟内**补打仍算打上了；超过 30 分钟，从午休开始到下班这段**不算工时**。
- 夜班跨零点的打卡，**归到上班那天**，不会算成第二天。
- 同一天一次卡都没打 → **旷工**；打过卡但缺了上班卡 → "未打卡（缺上班卡）"，**不算旷工**，系统会提醒，补卡即可。
- 一天只打了一次卡，且这次是在下班时间之后 → 系统当成**下班卡**，上班卡仍算缺。

### 5.4 打卡失败怎么办

| 提示 / 现象 | 处理 |
|---|---|
| 未开通远程打卡 | 找管理员开通 |
| 请先录入人脸 | 去「人脸信息」页录入 |
| 识别未通过 | 擦干净镜头、换到亮处、正脸对准、不戴帽子口罩，再试一次 |
| 服务暂时不可用 | 后台识别服务问题，不是你的责任，直接提交「补卡申请」 |
| 定位一直失败 | ① 别在微信里开；② 允许定位权限；③ 走到窗边 / 室外；④ 手机里打开"精确定位" |
| 在微信里打开了 | 页面会提示，点右上角「···」→ 在浏览器打开 |

## 六、人脸信息

菜单「**人脸信息**」：录入远程打卡用的人脸参考照。

**拍照要求**（不满足会被退回重拍）：

- 光线足，不背光、不阴阳脸；正脸，不歪头；画面里只有你一人；脸别太小；不戴帽子、口罩、墨镜。
- 支持 jpg / png / webp，最大 10MB；手机会直接调前置摄像头。
- 勾选"我同意录入本人人脸信息，仅用于打卡身份核验"后提交。

**注意**：录入后**你自己不能更换**。想换（换了发型、拍得不好）→ 联系管理员在「员工管理」里"清除人脸"，再重新录。

## 七、查看自己的考勤

### 7.1 我的记录

菜单「**我的记录**」：按**薪资周期**列出每天的明细。

- **薪资周期**：每月 **26 日 ~ 次月 25 日**为一个周期，页面上选的是周期的**结束月份**（选 10 月 = 9/26 ~ 10/25）。选好点「查询」。
- 顶部汇总：**实到天数 / 迟到次数 / 缺勤天数 / 总工时(h) / 请假天数**。
- 明细列：日期、星期、上班、下班、午间打卡、状态、工时(h)、迟到、早退、备注。
- 午间打卡一列：显示窗口和你的打卡时间；超出窗口才打的会提示"按未打卡计算工时"。
- 状态旁带红色定位提示的，表示打卡地点异常，管理员正在核实。

### 7.2 我的考勤日历

菜单「**我的考勤日历**」：月历视图，一眼看全周期。

| 颜色 | 含义 |
|---|---|
| 正常 | 按时出勤 |
| 异常 | 迟到、早退、缺卡、旷工等 |
| 休假 / 出差 | 请假或出差 |
| 周末 | 休息日（灰色） |

- 点某一天看当天详情（班次、上下班时间、状态）。
- 顶部统计：实到 / 应到、迟到次数、旷工天数、请假天数、总工时。
- 「上一周期」「下一周期」「回到本周期」切换周期。

## 八、提交申请

菜单「**提交申请**」，左边新建，右边是「我的申请记录」。

### 8.1 通用步骤

1. 选**申请类型**（请假 / 补卡 / 加班 / 出差 / 转班）。
2. 填时间和**申请原因**（必填）。
3. 选**审批人**（下拉里是你考勤组配置的审批人；没有下拉时自动走直属上级）。
4. 需要时上传**附件**（可选，最多 5 个，单个 ≤10MB，可逐个添加、单独删除）。
5. 点「提交」。**点一下就锁住**（按钮变"提交中…"），别连点。

> 页面顶部有提醒：**补卡、转班申请有效期 15 天**，超过 15 天没被处理会自动作废；加班、请假、出差不自动作废，但不能事后补交，所以更要留意进度。超过一周还没人处理，请联系审批人。

### 8.2 五类申请规则一览

| 类型 | 要填什么 | 规则 |
|---|---|---|
| **请假** | 假期类型、开始、结束 | 开始时间最早选到"现在往前 24 小时"，最多提前 3 个月；结束必须晚于开始 |
| **补卡** | 补卡日期、打卡类型、打卡时间 | 日期不能是未来；打卡类型：上班 / 下班 / 午间；同一天同一种卡只能有一张在途申请 |
| **加班** | 加班开始、结束 | 当天 24 点前提交；夜班可提前一天；一次只能对应一天；单次最长 24 小时 |
| **出差** | 目的地（可选）、开始、结束 | 开始不早于今天 0 点，最多提前 3 个月；通过后出差期间自动记全勤，无需打卡 |
| **转班** | 开始日期、结束日期（含当天）、目标班次 | 开始日期最早补报最近 3 天，最多提前 1 个月；一张最多连续 7 天；只能选自己考勤组里启用的班次 |

### 8.3 各类型要点

**请假**
- 假期类型：事假、病假、年假、婚假、产假、丧假、调休。
- 请假时长按**当天班次的上下班时间**取交集计算；休息日、节假日不算请假。
- 请假时间可以跨过班次的午间窗口，不用再拆成两段。

**补卡**
- 补上班卡只有比现有上班时间**更早**才生效；补下班卡只有比现有下班时间**更晚**才生效。
- 中午那次漏了或超窗口，选"**午间打卡**"，时间填在班次的午间窗口内。
- 打卡时间框要**点一下选好具体时和分**（部分手机浏览器会显示默认时间，没选就不算填写）。
- 管理员审批通过后，当天工时、迟到早退自动重算。

**加班**
- 只记**班次上下班时间之外**的部分；工作日的加班时间段**不能和当天班次的上下班时间重叠**。
- 时长扣除饭点（饭点时段由管理员按班次设置），再**按半小时向下取整**；**不足 0.5 小时不能提交**。
- 白班只能加班当天提交；**夜班员工**（加班那天排的是跨天班次）可提前一天提交，比如周五上夜班时，就能先交"周六 20:00 ～ 周日 08:00"的加班。
- 结束时间最晚只能选到开始日期的第二天 24 点前，不能一次选出好几天。
- 计时工模式的考勤组**不能申请加班**（工时按实际打卡时长算，不封顶）。

**出差**
- 出差区间里的休息日、法定节假日不记"出差"。

**转班**
- 用途：临时要换班次（比如白班的人这几天上夜班），不用再找管理员改排班。
- 审批通过后自动改排班，已有打卡和加班会按新班次重新计算。
- **这几天已有批准的请假或出差的日子不改班次**，并通知你；目标班次审批期间被停用时，排班不改并通知你。
- 白班 ↔ 夜班互转、且那几天已有打卡的，系统会提醒你和管理员**核对打卡归属**（旧打卡是按原班次归天的，转班不会自动重新归卡）。
- 提交后如果这段日期里已有批准的请假 / 出差，页面会提示"那几天的班次不会修改"。
- 通过后**无法自己撤销**，要改回去请联系管理员。

### 8.4 重复提交与进度

- **同一时间段重复提交会被拦下**（提示"已经提交过了"）；要改先撤销原来的单，或等它被驳回。
- 右侧「我的申请记录」列出单号、类型、状态、提交时间：

| 状态 | 含义 |
|---|---|
| 待审批 | 还没人处理，**可点"撤销"撤回** |
| 审批中 | 一级已批，等二级 |
| 已通过 | 已生效，考勤已回写 |
| 已驳回 | 被驳回，看审批意见，需要的话重新提交 |
| 已撤销 | 你自己撤回的 |
| 已作废 | 补卡 / 转班超过 15 天没处理，自动作废 |

- 已经有审批人处理过的单就撤不回了，有事找审批人沟通。

## 九、异常情况速查

| 情况 | 怎么处理 |
|---|---|
| 早上忘打上班卡 | 提交"补卡申请 → 上班打卡"；缺卡当天会收到提醒 |
| 下班忘打卡 | 补卡申请 → 下班打卡 |
| 午间忘打卡 | 补卡申请 → 午间打卡，时间填在窗口内；窗口结束 30 分钟内自己补打也算 |
| 考勤机坏了 / 打不上 | 补卡申请，原因写清楚 |
| 夜班下班打在第二天凌晨 | 正常，系统归到上班那天 |
| 白班晚上加班到第二天 1 点 | 提交加班申请（当天 24 点前）；下班打卡照常刷，系统按跨零点处理 |
| 工时看着不对 | 先看「我的记录」备注列；仍不对，截图找管理员（管理员可用"员工记录查询"核对） |
| 看到"旷工" | 当天一次卡都没打，或确实没出勤；如果是漏打，联系审批人 / 管理员 |
| 请假当天有打卡 | 按请假 + 打卡综合计算，以「我的记录」为准 |

## 十、附：班组长 / 主管（审批人）怎么用

班组长和主管比员工多两个菜单：「**待我审批**」「**发布公告**」。

### 10.1 待我审批

1. 菜单「**待我审批**」，页面每 30 秒自动刷新（打开详情弹窗时暂停）。
2. 上方按类型筛选：全部 / 补卡 / 请假 / 加班 / 出差 / 转班，各带数量。
3. 列表直接显示单号、申请人、部门、类型、**详情**（时间 / 时长 / 目的地等）、提交时间、原因，不用点进去就能看关键信息。
4. 处理方式：
   - **单条**：点「通过」或「驳回」，弹窗里写审批意见。**通过时意见可选，驳回时意见必填**。
   - **批量**：勾选多条 → 「批量通过」或「批量驳回」（一条驳回原因用于整批）。
5. 下方「我的已审批记录」可回看自己处理过的单和整单当前状态。
6. 点单号 / 详情可看申请详情和附件。

### 10.2 审批层级

考勤组可配置一级或二级审批：
- **一级**：只需班组长审批。
- **二级**：班组长通过后，再自动追加申请人的**直属上级**审批一次。

### 10.3 发布公告

菜单「**发布公告**」：填标题、内容，选发布范围发给下属。班组长 / 主管的发布范围固定为"我的直属下属"。可查看每条公告的已读情况，也可撤下。

## 十一、常见问题

**Q：我早上忘打卡，会算旷工吗？**
A：分两种。① 当天一次卡都没打 → 旷工；② 打过卡、只缺上班卡 → "未打卡（缺上班卡）"，不算旷工，会收到提醒，补卡即可。

**Q：远程打卡页说"未开通"或"请先录入人脸"？**
A：管理员开通权限 + 你在"人脸信息"页录人脸，两步都做好才能打。

**Q：为什么我的申请变成"已作废"？**
A：补卡 / 转班申请超过 15 天没人处理会自动作废。需要的话重新提交。

**Q：为什么加班申请提交不了？**
A：常见原因：① 加班时间和当天班次上下班时间重叠；② 不足 0.5 小时；③ 不是当天（夜班可提前一天）；④ 所在考勤组是计时工模式，不能申请加班；⑤ 同一时段已提交过。

**Q：转班通过了，为什么有几天没改？**
A：那几天已有批准的请假 / 出差，或目标班次被停用，系统会发通知说明。

**Q：定位一直失败？**
A：别在微信里开，允许定位权限，到窗边 / 室外，等待最多 20 秒。
