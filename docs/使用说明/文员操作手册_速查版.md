# 考勤系统文员操作手册（速查版）

> 适用对象：文员（分公司管理员的操作与此基本相同，差别见第三节）。按"我要做什么"和"菜单逐项"两个角度写，可当速查手册翻。
> 员工自己能做的事（打卡、申请、查记录）见《员工操作手册（速查版）》，本手册不重复。
> 版本：2026-10-26。

---

## 一、先看这张速查表

| 我要做什么 | 去哪里 | 关键点 |
|---|---|---|
| 新员工入职建号 | 员工管理 →「新增员工」或「待确认登记」→「确认录入」 | 填考勤组、班次、入职日，可直接排班 |
| 给员工排班 | 班值排班 → 批量排班 | 今天之前已排的班默认不覆盖 |
| 补卡（员工漏打） | 手动补卡 | 即时生效，不用审批，可撤回 |
| 查某人为什么是这个工时 | 员工记录查询 | 一页看排班、考勤、原始打卡、审批 |
| 发薪前出报表 | 月度报表 → 导出发薪考勤汇总表 | 默认上月 26 日～本月 25 日 |
| 核对数据有没有问题 | 数据核对 | 只读，列出疑点；每晚自动核对 |
| 改饭点（影响加班时长） | 饭点设置 | 先选考勤组，再选班次 |
| 员工忘了密码 | 员工管理 → 重置密码 | 可手动指定或随机生成 |
| 员工要换人脸照片 | 员工管理 → 清除人脸 | 员工再自己重录 |
| 员工离职 | 员工管理 → 停用 | 有记录的人不能删除，只能停用 |
| 看今天谁没来 | 数据看板 | 点卡片看具体人员 |

## 二、角色与权限

系统有 5 种角色：

| 角色 | 能做什么 |
|---|---|
| 管理员 | 权限最大；分"总部超级管理员"（不受范围限制）和"分公司管理员"（有管理范围） |
| 文员 | 管理页面与管理员基本一致，**受管理范围限制** |
| 主管 / 班组长 | 审批下属申请、给下属发公告，没有管理菜单 |
| 普通员工（临时工） | 打卡、查自己记录、提交申请 |

> "管理员""文员""主管""班组长"都是正式工，免考勤，不进看板和报表；只有"普通员工"是临时工。

文员登录后默认进入「**数据看板**」。左侧"管理"分组下共 13 个菜单（见第四节），另有员工通用的公告、考勤、申请菜单。

## 三、管理范围（最重要的概念）

- 每个管理员 / 文员账号可以被设置一个**管理范围**（某个部门及其下级）。范围内的数据才看得到、改得了；范围外的员工、考勤组、班次、设备、申请单都不可见。
- **不受范围限制的只有"总部超级管理员"**，能看和管全公司。
- 受范围限制的账号（分公司管理员 / 文员）**做不到**的事：

| 做不到的事 | 说明 |
|---|---|
| 设置 / 修改任何账号的"管理范围" | 只有总部超级管理员能设 |
| 把角色设成"管理员"，或编辑管理员账号 | 提示"无权…，请联系总部管理员" |
| 操作总部管理员账号（重置密码、编辑、补卡等） | 提示"无权操作总部管理员账号" |
| 修改自己管理范围根部门的上级、停用根部门 | 要总部处理 |
| 建 / 改不关联部门的"通用考勤组"、多分公司共用的班次 | 只有总部能写；分公司建考勤组至少要勾选一个本分公司部门 |
| 按"全公司""指定角色"发公告 | 只有总部能选这两个范围 |
| 设备的"归属部门"手动选择 | 只有总部能改，受限账号的设备自动归自己范围 |
| 看全部管理员的智能助手动作记录 | 受限账号只能看自己发起的 |

- 数据看板、月度报表、总审批记录、员工记录查询、数据核对等，都**只统计范围内的员工**。

## 五、数据看板

菜单「**数据看板**」：当天考勤实时统计，**数字每 30 秒自动更新**。

- **六张卡片**：总人数、已出勤、缺勤、迟到、请假、未打卡。**点卡片弹出具体人员名单**（工号、姓名、部门、上下班打卡、状态）。
- **出勤率** = 出勤 ÷ 应出勤。应出勤 = 已办入职的在职员工，去掉请假 / 节假日，以及今天没排班或休息又没打卡的人；**排了班但还没到上班时间的人（如晚上才上班的夜班）暂不计入**，页面会注明有多少人。
- **今日出勤率明细**：可切换"按考勤组 / 按班次"，列应出勤、出勤、未到上班时间、出勤率。
- **近 7 天出勤情况**：日期、应出勤、出勤、迟到、请假、旷工、出勤率；整天没有记录的日子（休息日、节假日）不统计。

## 六、员工管理

菜单「**员工管理**」：账号的全生命周期都在这里。

### 6.1 找人

- 左侧**部门树**：点部门显示该部门及下级的全部人员（"全公司""未分配"）。
- 顶部搜索：姓名 / 工号；状态筛选：全部 / 在职 / 已停用 / 黑名单；角色筛选。
- 列表列：姓名、工号、部门、角色、用工性质（正式工 / 临时工）、合同公司、手机、状态、操作。每 30 秒自动刷新。

### 6.2 新增员工

点「**新增员工**」，必填项带 *：

| 字段 | 说明 |
|---|---|
| 工号 * / 姓名 * | 工号唯一 |
| 初始密码 | 统一 `123456`，员工登录后自己改 |
| 角色 | 员工 / 班组长 / 主管 / 文员 / 管理员（受限账号不能选管理员） |
| 部门 * | 必选 |
| 考勤组 | 决定适用的班次、审批人、打卡地点 |
| 班次 + 排班天数 | **可直接排班**：先选考勤组再选班次；默认排到和该班次现有员工一样的天数，从入职日（已过则从今天）起排，需先填入职日期 |
| 直属上级 * | 选定部门后自动带出该部门主管，也可手动搜索 |
| 手机 * | 11 位大陆手机号 |
| 岗位、入职日期、身份证号、合同公司 | 合同公司 = 实际签合同发工资的主体 |
| 紧急联系人姓名 / 电话、家庭住址、身份证照片 | 照片 jpg/png/webp ≤10MB，上传新照片会替换旧的 |
| 允许远程打卡 | 勾选后该员工才能用手机远程打卡（出差 / 到不了考勤机的人） |
| 免考勤 | 不需要打卡的人（管理员 / 文员 / 办公室人员）：不再每天自动记旷工，报表里旷工天数为 0 |
| 推送到哪些考勤机 | 只有勾选的考勤机才会收到这个人的工号 / 人脸；不限分公司，方便借调 |
| 管理范围 | 仅总部超级管理员能设；只对管理员 / 文员有意义 |

### 6.3 编辑、详情与状态变更

行内操作按钮：

| 按钮 | 作用 | 注意 |
|---|---|---|
| 详情 | 看完整资料 | |
| 编辑 | 改资料、改部门、改考勤组 | 编辑管理员账号受限（见第三节） |
| 停用 / 启用 | 停用后无法登录 | 离职员工用这个 |
| 拉黑 / 移出黑名单 | 禁止登录，**工号永不再用** | 慎用 |
| 重置密码 | 弹窗里可手动指定新密码（≥6 位），留空则随机生成 | 新密码当面 / 电话告知员工，别群发 |
| 清除人脸 | 清除参考照，员工可重新录入 | 员工录入后自己不能换，换人脸都走这里 |
| 删除 | 彻底删除 | **有考勤 / 打卡 / 申请历史的人、做过审批人的人不能删，只能停用** |

批量操作：勾选多人后「批量启用」「批量停用」。

### 6.4 新员工扫码登记

1. 在员工管理页点「**登记二维码**」，选分公司，得到该分公司专属的二维码 / 链接（「复制链接」可发送）。每个分公司的码不同，扫码登记的人**自动归到对应分公司**。
2. 新员工用手机扫码，填：姓名、手机号、身份证号、岗位、劳务公司、家庭住址、紧急联系人、**身份证照片（必传）**，提交后等待确认。
3. 你在「**待确认登记**」页签看到列表（姓名、手机号、身份证号、意向分公司、提交时间），每 30 秒自动刷新。
   - **确认录入**：弹窗里补全工号、部门、考勤组、班次、入职日等，直接排班并正式建号；
   - **驳回**：可写驳回原因。

## 七、员工信息

菜单「**员工信息**」：员工档案卡片。

- 筛选：部门、姓名 / 工号；底部显示"按当前筛选条件，共 N 人"。
- 每张卡片分块展示：组织信息（部门、考勤组、直属上级、岗位）、联系方式、证件信息（身份证号及照片）、紧急联系人、合同 / 入职信息、账号信息（创建 / 最近修改 / 最近登录）。
- 「**导出为 Excel**」按当前筛选导出；「**打印**」直接打印。
- 含身份证等敏感信息，导出和打印后请妥善保管。

## 八、员工记录查询

菜单「**员工记录查询**」：遇到"这个人为什么是这个工时 / 为什么旷工"，在这里一页查清。

1. 输入姓名或工号，选考勤记录日期范围（默认最近 30 天），点「查询」。
2. 同名的人会列出来（工号、姓名、部门、考勤组、状态），**点工号**看详情。范围外的人搜不到。
3. 详情包含：
   - **基本信息**：部门、职位、考勤组、计时工模式起始日、角色、账号状态（含免考勤）、入职日、直属上级、手机、**绑定的考勤机**；
   - **排班**（今天前 14 天到后 45 天）：日期、班次、上下班时间（跨天标注）、休息日；**没排班的日子标红**，有打卡但没排班会特别标出；
   - **考勤记录**：日期、班次、上下班、工时、加班、请假、状态、迟到分钟、午间窗口、备注，顶部有正班合计和加班合计；
   - **原始打卡**：每次打卡的时间、类型、来源（考勤机 / 手机）、地址；
   - **审批单**：这段时间该员工的全部申请及状态。

> 排查口诀：先看排班有没有（红行），再看原始打卡，再看审批单有没有补卡 / 加班 / 转班改了什么。

## 九、手动补卡

菜单「**手动补卡**」：代员工补上班卡、下班卡、午间打卡，**保存即生效，不需要审批**，规则与员工自己提交的补卡申请一致。

操作步骤：

1. 选**员工 ***、**考勤日期 ***（对应考勤记录所属的那一天；**夜班取上班当天的日期，不是下班那天**）。
2. 点「**查询当前打卡记录**」：能看到这天的班次、午间窗口和全部原始打卡——**补之前先看一眼**。
3. 选**补哪种卡**（上班卡 / 下班卡 / 午间打卡）和**补的打卡时间**。夜班的下班卡、过了零点的午间卡，勾「**第二天**」。
4. 备注（可选），点「保存」。

规则要点：

- 默认和员工自己补卡一样：上班卡只有比现有的**更早**、下班卡只有比现有的**更晚**才生效，防止覆盖好数据。
- 确认已有的时间填错了、要改掉它，才勾「**强制覆盖已有的上班 / 下班时间**」。
- 补午间卡只新增一条午间打卡，不动上下班时间；时间要落在班次的午间窗口内。
- 保存后按该员工当天的班次规则（含午间必打卡窗口）**自动重算工时、迟到 / 早退、状态**。
- 页面下方「补卡记录」列出最近的手动补卡操作，每条可「**撤回**」：这天的上下班时间、状态、工时恢复成补卡前的样子。
- 不能给范围外或总部管理员的账号补卡。

## 十、数据核对

菜单「**数据核对**」：把一段日期内每条考勤记录，按**现行规则**从原始打卡、班次、午间窗口、加班单**重新算一遍**，和系统里存的工时、加班对比，找出对不上的。**只读，不改任何数据**。

- 选开始、结束日期（最长 63 天），点「核对」。
- 结果先给按类型的汇总（可点类型筛选），再列疑点明细：日期、工号、姓名、考勤组、类型、系统里的值、应为值、说明。明细最多显示前若干条，太多请缩小日期范围或按类型筛。

疑点类型：

| 类型 | 含义 | 常见处理 |
|---|---|---|
| 工时与打卡不符 | 存的工时和现行规则算出来不一致 | 多半是规则变了、补排班或补传了打卡 |
| 加班多记 / 加班少记 | 记录上的加班和加班单合计不一致 | 查加班单日期、是否订正过 |
| 有打卡但没排班 | 有打卡，那天没排班 | 补排班；**深圳GA考勤组长期不排班，已被忽略** |
| 排班类型与打卡时间对不上 | 排的白班，打卡却像夜班（或反过来） | 多半排错了班次，核对后改排班 |
| 有打卡却记旷工 | 有上班卡，状态却是旷工 | 重新结算 / 联系开发核对 |
| 上下班时间倒挂 | 下班不晚于上班 | 查是不是夜班跨天归属错了，必要时手动补卡 |

**每晚自动核对**：系统每天凌晨 4 点之后自动核对最近 14 天。

- 其中"结算时还没排班、后来补排了班"导致的工时不符，会**自动按现行规则改回**（只改工时，不动状态、迟到早退、加班、请假）。
- 其他疑点**只通知，不自动改**。
- 有疑点时，**管理员**会收到"数据核对"通知，点通知直接进本页。失败会隔 30 分钟重试。

> 补充：转班审批通过后，如果白班 ↔ 夜班变了且当天已有打卡，系统也会给管理员发"转班后需核对打卡归属"的通知，需要人工核对是否要订正打卡归属。

## 十一、班值排班

菜单「**班值排班**」：班次定义 + 排班。

### 11.1 选考勤组

左上角考勤组列表（可搜索、多选）→「**载入所选组**」。载入后下方显示这些组的班次，并可在"批量排班"里跨组勾人。

### 11.2 新增 / 修改班次

点「新增班次」或班次行的编辑：

| 字段 | 说明 |
|---|---|
| 所属考勤组 / 班次名称 / 标识颜色 | |
| 上班时间 / 下班时间 | 下班不晚于上班会被识别为跨天（夜班） |
| 迟到容忍（分钟）/ 早退容忍（分钟） | 晚这么多分钟内不算迟到 / 早退 |
| 加班起算（分钟）/ 标准工时（小时） | |
| 跨天班次（夜班） | 勾选 |
| 午间必打卡窗口 | 选填，可配多段（如上午茶歇 + 午休）；按本班次实际时间设置；**窗口结束后 30 分钟内打卡也算打上**；漏打则午休起到下班不算工时 |
| 每周休息日 | 勾选的这几天不用上班，三班倒等可自由选，不限周六日 |
| 同时重算这个班次的历史工时 | 从某日起（**最多往前 93 天**）：改了午间窗口或上下班时间后建议勾上，**只重算工时和午间命中**，不动考勤状态、迟到早退、加班、请假；不勾则旧记录仍按旧设置 |

停用班次：行内「停用」。**共用班次（多个分公司在用）只有总部能改。**

### 11.3 批量排班

1. 选班次；选开始、结束日期。
2. 选人：勾"所选组全部成员"，或在列表里勾选任意组的人（可按部门筛选、搜索姓名 / 工号），支持跨组混排。
3. 「确认排班」。
4. **默认不覆盖今天之前已有的排班**（避免历史工时被按新班次重新解释）；确实要改，勾「允许覆盖今天之前已经排过的班次」。
5. 排班保存后，系统会按班次对账已有的加班记录（只减不增）。

### 11.4 看与导出已排班

下方「已排班情况」选日期范围查询，按日期列出班次、人数、排班人员；「**导出排班记录**」导出 Excel。

> 提示：员工自己也可以通过"转班申请"临时改自己的班次，审批通过后自动改排班，你不用再手动改。

## 十二、饭点设置

菜单「**饭点设置**」：设置**加班申请**时用来扣除的吃饭时间。

- **只影响加班时长**：加班起止时间压到饭点时段的部分不计入，然后按半小时向下取整；不足 0.5 小时不能提交加班申请。
- 正班实际工时、请假时长**不看这里**，一律按默认饭点算。
- **默认饭点**：12:00–13:00、17:30–18:00、00:00–01:00、05:30–06:00。
- **优先级**：班次单独设置 > 考勤组设置 > 默认。算哪个班次：加班开始那天他排的班次（没排班就按最近排的班次）。
- 操作：左边选考勤组，下面列出该组的班次，点"整个考勤组"或某个班次，编辑时段后「保存」。「恢复默认」可取消单独设置（班次则改为跟随考勤组）。
- 限制：一段饭点**不能跨 0 点**（跨的请拆成两段）；每段最长 4 小时；段与段不能重叠；最多 8 段；整行留空保存 = 删掉这一行。
- 管理员和文员都能改，但**只能改自己管理范围内的考勤组和班次**。
- **改了以后**：只影响之后新提交的加班申请和审批通过的回写，**已存好的加班时长不会自己变**，改历史数据要找开发人员核对后处理。
- 改动会直接影响加班时长，改之前先确认。

## 十三、考勤组管理

菜单「**考勤组管理**」：决定一批人用什么规则。

列表列：考勤组名称、所属公司、所属部门、人员数、审批人、审批层级、打卡地点、午休 / 晚餐、状态、操作（编辑 / 启用·停用 / 删除）。

新建 / 编辑考勤组的字段：

| 字段 | 说明 |
|---|---|
| 考勤组名称 * | |
| 午休 / 晚餐时长 | 自 2026-09-29 起工时统一按固定时段扣，这里**不再影响工时**，仅供查看历史 |
| 所属部门 | 勾选的部门**长期跟随本组**：现有及以后新增 / 调入的员工自动归入；所属公司按勾选部门自动带出 |
| 计时工模式起始日 | 留空 = 普通考勤组。填了之后，从这一天起组内员工按**实际打卡时长**算工时（最后一次下班卡 − 第一次上班卡，扣午饭 1 小时、晚饭 0.5 小时，不封顶），**没有加班、休息日、旷工、迟到早退**；午间窗口漏打只算窗口开始之前的工时；00:00–07:00 的打卡无效（夜班有单独规则）。起始日之前的记录不变 |
| 启用定位打卡 | 勾选后配置**打卡地点**（可多个，落在任一地点有效半径内即成功），可地图选点、按名称搜索 |
| 审批层级 * | **一级**：只需选中的班组长审批；**二级**：班组长通过后再追加申请人的直属上级审批 |
| 审批人（班组长）* | 必选，可多选；员工提交申请时从这里选一个；只能选"班组长"角色且在职的人；名单随所属部门勾选自动筛选 |

其他：

- 停用 / 启用考勤组：确认后生效。
- 删除考勤组：会清空组内在职员工的考勤组归属（需另外分配），并解除部门关联，**慎用**。
- 通用考勤组（不关联部门）只有总部能建 / 改。

## 十七、总审批记录

菜单「**总审批记录**」：范围内全部申请及进度。

- 只保留**最近 2 个月**的数据（页面顶部会写明起止）。
- 筛选：提交日期（起 / 止）、类型、状态（待审批 / 审批中 / 已通过 / 已驳回 / 已撤销 / 已作废）、部门（含下级）、姓名 / 工号 / 单号。
- 列表：单号、申请人、部门、申请内容、时长、申请理由、提交时间、审批流程 / 意见（每一级审批人和意见）。支持翻页。
- 「**导出 Excel**」按当前筛选导出。
- **审批进度**面板：还没审批完的申请有多少张、涉及哪些审批人；每位审批人显示角色、部门、"现在轮到其审批"的数量、排在后续级别的数量、**最早一张已挂多少天**（≥3 天标红）、最近登录时间；点「查看申请」看他手上的待审批单。

## 二十一、日常工作流

### 21.1 新员工入职

1. 员工扫分公司二维码登记（或你直接「新增员工」）。
2. 「待确认登记」→「确认录入」：补工号、部门、考勤组、班次、入职日、直属上级、合同公司。
3. 需要手机打卡的：勾"允许远程打卡"；需要刷脸的：勾"推送到哪些考勤机"。
4. 告知员工：工号 + 初始密码 123456，让员工录入人脸。

### 21.2 每天

1. 看「数据看板」：缺勤、未打卡、迟到名单，必要时跟进。
2. 有员工反馈漏打卡：先「员工记录查询」确认，再「手动补卡」或让员工提补卡申请。
3. 看「通知」铃铛：数据核对、转班后核对打卡归属等提醒。

### 21.3 每周

1. 「总审批记录」看审批进度，催办久挂的单。
2. 检查新增员工是否都排了班（报表"没排班"标记、数据核对"有打卡但没排班"）。

### 21.4 每月（发薪前）

1. 「数据核对」选整个周期，清掉疑点。
2. 「总审批记录」确认没有待处理的补卡 / 请假 / 加班。
3. 「月度报表」导出发薪考勤汇总表（以及需要的打卡时间表 / 原始打卡）。
4. 如需单人明细：报表行的"导出每日明细"。

### 21.5 员工离职

1. 「员工管理」→ 停用（有历史的不能删）；需要禁止再入职的才拉黑。
2. 如有做审批人，先到「考勤组管理」换掉审批人名单。

### 21.6 改班次或饭点之后

1. 班次改了上下班 / 午间窗口：编辑班次时勾「同时重算这个班次的历史工时」。
2. 饭点改了：只影响之后的加班申请；历史加班要订正找开发处理。

## 二十二、常见问题

**Q：员工说打不了卡？**
A：按顺序查：账号状态是否在职 → 远程打卡是否开通 → 是否录过人脸 → 考勤机的话是否勾选了"推送到哪些考勤机"、设备是否在线（考勤机管理看最近在线时间）→ 是否排了班。

**Q：为什么报表里某人没排班标记？**
A：期间有天数没排班，去「班值排班」补排；补排后系统会把当时按无班次算的工时自动重算。

**Q：员工的工时和他自己算的不一样？**
A：用「员工记录查询」看班次、原始打卡、午间窗口命中情况；常见原因是午间窗口漏打（窗口结束 30 分钟后才打）、饭点扣除、排错班次。

**Q：数据核对出现大量"工时与打卡不符"？**
A：多半是规则调整后历史没重算或补排了班。夜里会自动订正"补排班"类；其他类型找开发人员评估后订正。

**Q：能给总部管理员、范围外的人操作吗？**
A：不能，提示"无权…请联系总部管理员"。

**Q：误操作了怎么办？**
A：手动补卡可「撤回」；其他数据修改（员工资料、班次、考勤组）没有撤回，改之前先核对；涉及历史数据订正请联系开发人员，他们会先备份再改。
