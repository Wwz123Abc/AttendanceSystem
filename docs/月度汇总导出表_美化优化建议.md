## 1. 原表的问题（逐条对照截图核对过）

1. **标题打开就看不见**：标题在第 1 行 56 列里居中（`TitleStyle` 是 `Center`，又合并了 `A1:BD1`），冻结窗格后一打开，左上角是空的，标题跑到了很右边。
2. **说明文字太长**：第 2 行是一整行很长的说明，屏幕上只能看到开头一小段，后面要一直往右拖才看得完。
3. **表头不显眼**：表头用的是 `HeaderStyleNoFill`，只有加粗、没有底色，跟数据行差别不大；56 列也没有分组，找列要一个个数。
4. **格线太重**：每个格子都是黑色细边框（`ApplyBorder`），满屏都是网格。
5. **颜色太刺眼**：夜班是纯黄（`HSSFColor.Yellow`，`FFFF00`），休息日是深灰（`Grey25Percent`，`C0C0C0`），成片的色块很抢眼。
6. **全部居中**：姓名、考勤组、部门、公司名都居中（`DataStyle` 是 `Center`），长公司名两头都被截掉（屏幕上只剩"川市科诺劳务派遣公司"）。
7. **星期只在周末标**：只有周末写成"29六""30日"，工作日看不出是星期几。
8. **小数位不齐**：同一列有的是 `56`、有的是 `35.5`，数字对不齐。
9. **打印看不清**：56 列压进一页 A4 宽度（纸张没指定），打出来字很小，也没有页码。
10. **筛选下拉框没有列名**：固定列/统计列的名字写在第 3 行、并跟第 4 行纵向合并，而筛选箭头挂在第 4 行——下拉框里这些列大概率没有标题（第 10 轮清单 #3，建议 3 顺带解决）。

## 2. 优化建议（每条：现状 → 建议 → 具体参数）

### 建议 1：标题靠左，拆成两段

- **现状**：`A1:BD1` 合并后居中，打开看不到。
- **建议**：第 1 行不再合并。`A1` 写主标题"月度考勤汇总"，`C1` 写"统计周期 2026-08-26 至 2026-09-25（31 天）· 共 572 人"。
- **参数**：主标题 16 号、加粗、深蓝 `1F3864`、靠左；副标题 11 号、灰色 `7F7F7F`、靠左。行高 34。
- **说明**：不用"富文本"（同一格里两种字号）是因为有的软件显示不出来，拆两格最稳。

### 建议 2：第 2 行改成彩色图例块

- **现状**：一整行几十个字的说明，挤在一个合并单元格里。
- **建议**：还是只占第 2 行（**不新增行，表头和数据的行号都不变**），拆成几个小块：

  | 位置 | 内容 | 样式 |
  |---|---|---|
  | A2:F2 | 报表生成时间：2026-09-24 16:58 | 9 号灰字、靠左 |
  | G2:H2 | 夜班 | 淡黄底 `FFF2CC` + 细框 |
  | I2:K2 | 休息/节假日 | 浅灰底 `F2F2F2` + 细框 |
  | L2:N2 | 迟到/早退 | 深橙字 `C55A11`、加粗 + 细框 |
  | O2:Q2 | 缺卡/旷工 | 深红字 `C00000`、加粗 + 细框 |
  | R2 到每日最后一列 | 格内数字 = 当日工时（小时，不足半小时舍去）；空白 = 应出勤但没有工时 | 9 号灰字、靠左 |
  | 统计列区域 | (分) = 分钟　(h) = 小时　最后一行"合计"会随筛选结果变化 | 9 号灰字、靠左 |

- **说明**：原说明里"周末列头如'29六'前面的数字是日号"这句，改成建议 4 之后就不需要了。行高 22。

### 建议 3：表头改成"分组行 + 列名行"两层

- **现状**：固定列和统计列的名字在第 3 行、跟第 4 行纵向合并；只有每日列上面有一个"考勤结果"分组。
- **建议**：
  - **第 3 行（分组行）**：深蓝底 `1F3864`、白字加粗，按下表合并；
  - **第 4 行（列名行）**：所有列名都写在这一行，按分组用不同浅色底、深蓝加粗字；筛选箭头本来就挂在这一行，**改完下拉框每列都有名字**。

  | 分组名（第 3 行） | 覆盖的列 | 列名行底色（第 4 行） |
  |---|---|---|
  | 基本信息 | 姓名 ~ 合同公司（6 列） | `D6DCE4` 蓝灰 |
  | 考勤结果（每日工时，单位：小时） | 每日列 | 工作日 `EEF3FA`、周末 `E7E6E6` |
  | 出勤与工时 | 出勤天数、请假天数、休息天数、正班工时(h) | `DDEBF7` 浅蓝 |
  | 迟到 · 早退 · 缺卡 · 旷工 | 迟到时长(分) ~ 旷工天数（7 列） | `FBE5D6` 浅橙 |
  | 出差 · 夜班 · 加班 | 出差时长(h) ~ 节假日加班(h)（7 列） | `E2EFDA` 浅绿 |
  | 对照 | 应出勤天数 | `DDEBF7` 浅蓝 |

- **参数**：第 3 行行高 20；第 4 行行高 34（要放两行字）。"考勤结果"这个分组横跨 31 列，文字**靠左**（居中的话冻结窗格后看不到），其余分组居中。
- **说明**：列的顺序、每列在第几列、数据从第几行开始都不变，代码注释里"新列只能加在最后"的约束不受影响；以后如果在最后加列，记得同步扩大最后一个分组的范围。

### 建议 4：日期表头每天都显示星期

- **现状**：工作日是"26""27"，周末是"29六""30日"。
- **建议**：一律写成两行："26"下面一行"三"。工作日深蓝字，周末灰字 `808080` + 灰底 `E7E6E6`，一眼就能看出周末。
- **参数**：9 号加粗，居中，自动换行。

### 建议 5：格线改浅灰，分组之间加分隔线

- **现状**：所有格子黑色细边框。
- **建议**：
  - 普通格子：细边框，颜色浅灰 `D9D9D9`；
  - 每个分组的最后一列右边线：细边框，颜色深一点 `8497B0`（合同公司、每日最后一天、正班工时、旷工天数、节假日加班这几列的右侧）；
  - 表头最后一行（第 4 行）下边线：中粗、深蓝 `1F3864`；
  - 继续关掉 Excel 默认网格线（现在已经关了）。

### 建议 6：颜色调柔和

| 用途 | 现在 | 建议 |
|---|---|---|
| 夜班当天格子底色 | 纯黄 `FFFF00` | 淡黄 `FFF2CC` |
| 休息日/节假日（当天没工时）底色 | 深灰 `C0C0C0` | 浅灰 `F2F2F2` |

### 建议 7：文字列靠左、数字居中

- **现状**：全部居中。
- **建议**：姓名、考勤组、部门、职位、合同公司**靠左、缩进 1 格**；工号、每日格子、统计数字**居中**。
- **合同公司列**：不要用"缩小字体填充"（试过，长名字会缩到看不清），超出部分直接截断显示开头即可。根本解决要靠第 10 轮清单 §4 说的"合同公司改成受控字典"（现在有 41 种写法，长的如"深圳市技为直聘人力资源有限公司"）。

## 4. 实施要点（NPOI 参考写法，未编译验证）

### 4.1 自定义颜色

NPOI 自带的老调色板（`HSSFColor.Xxx.Index`）里没有上面这些柔和颜色，xlsx 可以直接用任意 RGB：

```csharp
// 需要：using NPOI.XSSF.UserModel;
// "FFF2CC" 这样的 16 进制色值 → NPOI 的自定义颜色
private static XSSFColor Rgb(string hex) => new(Convert.FromHexString(hex));

// 在一个已有样式基础上换底色（夜班、休息日、各组列名都用它派生）
private static ICellStyle WithFill(XSSFWorkbook wb, ICellStyle from, string hex)
{
    var s = (XSSFCellStyle)wb.CreateCellStyle();
    s.CloneStyleFrom(from);
    s.SetFillForegroundColor(Rgb(hex));
    s.FillPattern = FillPattern.SolidForeground;
    return s;
}

// 浅灰细边框；isGroupEdge=true 时右边线用深一点的颜色当分组分隔线
private static void ApplyLightBorder(XSSFCellStyle s, bool isGroupEdge = false)
{
    s.BorderTop = s.BorderBottom = s.BorderLeft = s.BorderRight = BorderStyle.Thin;
    var gray = Rgb("D9D9D9");
    s.SetTopBorderColor(gray);
    s.SetBottomBorderColor(gray);
    s.SetLeftBorderColor(gray);
    s.SetRightBorderColor(isGroupEdge ? Rgb("8497B0") : gray);
}

// 字体颜色
private static IFont ReportFont(XSSFWorkbook wb, double size, string hex, bool bold = false)
{
    var f = (XSSFFont)wb.CreateFont();
    f.FontName = ReportFontName;
    f.FontHeightInPoints = size;
    f.IsBold = bold;
    f.SetColor(Rgb(hex));
    return f;
}
```

**注意样式数量**：xlsx 最多约 64000 个样式。"是否分组边界"会让每种样式多一个变体（普通/夜班/休息/橙字/红字 × 普通列/边界列），
一定要像现在这样在循环外**提前建好、循环里复用**，建议用一个小字典按 `(种类, 是否边界列)` 缓存，不要在循环里新建。

```csharp
var bandRow = sheet.CreateRow(2);   // 第 3 行：分组行

bandRow.HeightInPoints = 20;

{

    if (g.Last > g.First)   // 只有一列的分组不能合并（NPOI 会报"合并区至少要 2 个格子"）
        sheet.AddMergedRegion(new CellRangeAddress(2, 2, g.First, g.Last));
}
// 固定列、统计列的列名写到第 4 行，不再跟第 3 行纵向合并（原来的 MergeHeaderVertically 不再使用）
```

### 4.3 日期表头 / 统计列表头换行

```csharp
// 每天都写"日号↵星期"；DayOfWeek 周日=0，换算成"一二三四五六日"的下标
var label = $"{date.Day}\n{"一二三四五六日"[((int)date.DayOfWeek + 6) % 7]}";

// 统计列表头：单位换到第二行；5~6 个字没有单位的在中间换行（文字本身不变）
static string WrapHeader(string h) =>
    h.Contains('(') ? h.Replace("(", "\n(")
    : h.Length >= 5 ? h.Insert(h.Length == 6 ? 4 : 3, "\n")
    : h;
```

列名行样式要打开 `WrapText = true`。

### 4.4 数字格式

```csharp
var fmt = wb.CreateDataFormat();
hourStyle.DataFormat   = fmt.GetFormat("0.0;-0.0;\"-\"");     // 工时列
minuteStyle.DataFormat = fmt.GetFormat("#,##0");              // 分钟列

totalDayStyle.ShrinkToFit = true;                             // 放不下时自动缩小，不显示"###"
```
